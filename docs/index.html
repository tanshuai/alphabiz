Evidence before release

The next binary must earn production status

AlphaBiz will not publish a new production binary until each gate has current, reviewable evidence.

  1. 1
    Security

    No tracked signing keys or credential material; modern scanning and least-privilege automation.

  2. 2
    Reproducibility

    A clean checkout can install dependencies and build through a documented, repeatable path.

  3. 3
    Quality

    Required CI, static analysis, and platform smoke tests pass from the release candidate.

  4. 4
    Release integrity

    Artifacts, checksums, provenance, and signing expectations are explicit and independently checkable.
